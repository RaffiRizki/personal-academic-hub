# Personal Academic Hub

Struktur proyek React + Vite + Tailwind mengikuti standar yang rapi (components & pages).
Jalankan:

```bash
npm install
npm run dev
```

**Halaman:**
- `/` Beranda
- `/materi` Materi Kapita Selekta (berisi bagian Pengantar, Fungsi, SWOT/Porter, SWEBoK, TA, KP & Skripsi, Open Source)
- `/portfolio`
- `/about`
- `/contact`
